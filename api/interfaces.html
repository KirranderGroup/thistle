pyxscat.interfaces: wavefunction adapters¶

Adapters that turn the output of electronic structure packages into a pyxscat.Wavefunction (basis set + density matrices).

pyxscat.interfaces.pyscf¶

PySCF adapter: turns PySCF objects into a pyxscat.Wavefunction.

The basis is taken from the Mole object in memory (no Molden file). Spherical (pure) basis sets are handled by expressing the density matrices in the underlying Cartesian functions.

pyxscat.interfaces.pyscf.basis_from_mole(mol)[source]¶

Cartesian Basis of a PySCF Mole (functions ordered as in mol.cart = True).

pyxscat.interfaces.pyscf.from_density(mol, dm1, dm2=None, mo_coeff=None, label='')[source]¶

Wavefunction from spin-summed density matrices.

If mo_coeff is given, dm1 and dm2 are in that molecular-orbital basis (as returned by PySCF’s make_rdm1 / make_rdm2 of post-HF methods); otherwise they are in the AO basis of mol. dm2 follows PySCF’s convention (chemists’ notation, trace N(N-1)).

pyxscat.interfaces.pyscf.from_scf(mf, with_dm2=False)[source]¶

Closed-shell (RHF/RKS) wavefunction. The mean-field two-electron term does not need the four-index array (see pyxscat.mean_field); set with_dm2=True to build it anyway.

pyxscat.interfaces.pyscf.from_cc(mycc, factored='auto')[source]¶

CCSD wavefunction (unrelaxed lambda densities from PySCF).

factored

True: the two-particle density as a sum of 7 nocc^2 + 4 products of one-particle matrices (pyxscat.ccsd; memory 2 K nao^2 instead of nao^4, the kernels contract it directly, same numbers to 1e-13). False: PySCF’s four-index array. "auto" (default): factored beyond FACTORED_ABOVE basis functions.

pyxscat.interfaces.pyscf.from_ci(myci, factored='auto')[source]¶

CISD wavefunction. factored: as in from_cc() (K = 4 nocc^2 + 2 products of one-particle matrices instead of the n^4 array; pyxscat.ccsd.factored_rdm2_cisd()).

pyxscat.interfaces.pyscf.from_fci(mol, mo_coeff, civec, norb, nelec, factored='auto')[source]¶

Full CI wavefunction in the orbitals mo_coeff[:, :norb] (no frozen core). factored: as in from_casscf().

pyxscat.interfaces.pyscf.from_fci_solver(solver, mo_coeff, state=None, factored='auto')[source]¶

A standalone PySCF FCI or selected-CI solver after kernel() (fci.FCI(mf), fci.selected_ci.SCI). PySCF does not keep the orbitals in the solver (only the integrals), so they are given: mo_coeff is the array or the SCF object. state selects a root (0-based) when nroots > 1; the densities come from the solver’s own make_rdm12.

pyxscat.interfaces.pyscf.from_casscf(mc, state=None, factored='auto')[source]¶

CASSCF/CASCI wavefunction; for state-averaged calculations pick the root with state.

factored

True: the 2RDM as products of one-particle matrices (core-core and core-active blocks from the core and active 1RDMs, the active block diagonalised as a (pq) x (rs) matrix, at most n_act (n_act + 1) / 2 + 3 terms; pyxscat.ci.embed_core()), never the n_AO^4 array. False: the four-index array over the core and active orbitals, transformed to AOs. "auto" (default): factored beyond FACTORED_ABOVE basis functions.

pyxscat.interfaces.molden¶

Molden files: basis set, geometry and molecular orbitals from any program that writes them (Molpro, Molcas/OpenMolcas, BAGEL, ORCA, PySCF, Psi4, …).

The reader does not depend on any electronic structure package. Spherical (pure) shells are expressed exactly in Cartesian functions, so the MO coefficients it returns refer to the Cartesian Basis it builds.

Conventions handled¶

  • [Atoms] AU or Angs; Fortran D exponents.

  • [5D], [5D7F], [5D10F], [7F], [9G] flags (default: Cartesian 6D/10F/15G).

  • Molden component order: d xx yy zz xy xz yz; f xxx yyy zzz xyy xxy xxz xzz yzz yyz xyz; g xxxx yyyy zzzz xxxy xxxz yyyx yyyz zzzx zzzy xxyy xxzz yyzz xxyz yyxz zzxy; spherical m = 0, +1, -1, +2, -2, …

  • Contraction coefficients refer to normalised primitives; the contracted function is renormalised.

  • Cartesian components of d, f, g shells are normalised either each to one ("unit") or all with the factor of the x^l component ("axis"). Programs differ; with the default cart_norm="auto" the convention that makes the occupied MOs orthonormal is chosen.

pyxscat.interfaces.molden.solid_harmonic(l, m)[source]¶

Real solid harmonic of degree l and order m as {(lx, ly, lz): coefficient} (unnormalised, Molden/Helgaker sign convention: d+1 = xz, d-1 = yz, d+2 = x^2-y^2, d-2 = xy).

Build a Wavefunction.

Without arguments the 1RDM is built from the occupations in the file (enough for elastic scattering and for the mean-field total). pyxscat.interfaces.molden.scf_energy(path, cart_norm='auto', reorder='auto', npoints=4000, seed=0)[source]¶

Energy of the single determinant (or natural-orbital 1RDM, Hartree-Fock-like) defined by the occupations in a Molden file, with exact integrals from PySCF.

Used to validate a program’s Molden conventions: for an SCF Molden file the result must equal the program’s SCF energy. It matches only if the basis, the contraction normalisation, the Cartesian/spherical conversion, the component order and every sign are read correctly. Closed-shell (or spin-summed restricted) files only. Returns (energy, fit_residual).

pyxscat.interfaces.molcas¶

(Open)Molcas RASSCF/CASSCF wavefunctions: CI vector from the output file, orbitals from the Molden file written by the same run (*.rasscf.molden).

The RASSCF input must print the full CI vector, PRWF = -1 (or a threshold small enough for the precision you need). Molcas prints the coefficients with five decimals; the vector is renormalised after reading. Only calculations without point-group symmetry (C1) are supported so far.

Example:

from pyxscat.interfaces import molcas
wf = molcas.from_rasscf("molcas.log", "molcas.rasscf.molden", root=1)

pyxscat.interfaces.molcas.read_mrci_output(path)[source]¶

Parse the MRCI (uncontracted multireference SDCI / ACPF) section of an OpenMolcas output run with THRPrint = 0.0 (the complete CI vector printed).

Returns a dict: nfrozen (orbitals frozen at the integral transformation, doubly occupied and not shown), norb_ci (correlated orbitals = inactive + active + virtual), nelec (correlated electrons), spin (2S+1), and states {k: dict(energy, csfs, coeffs)} where each CSF is (orbitals, step): the 1-based orbital indices (within the symmetry; with Group = NoSym these are global) in the order of the spin coupling (virtual, inactive, active), and the step string over them (0, u, d, 2). Orbitals not listed are empty. Only NoSym runs are supported (one irrep).

pyxscat.interfaces.molcas.mrci_rdms(info, state=1, factored=False, method='external')[source]¶

Spin-summed 1- and 2-RDMs of one MRCI state in the MO basis (frozen orbitals, then the correlated ones, as numbered by Molcas). The CSFs are expanded in determinants, the determinant bits placed on the orbital indices, and the RDMs built over the correlated orbitals (inactive + active + virtual, any number): method="external" (default) uses the at-most-two-electrons-in-the-virtuals structure (pyxscat.ci.make_rdm12_external()), any other value the general builders of pyxscat.ci.make_rdm12(). The frozen orbitals are added as a doubly occupied core. factored=True returns a FactoredDM2 (feasible up to ~80 orbitals in all: beyond that the eigendecomposition of the active block is too large, keep the four-index array).

pyxscat.interfaces.molcas.from_mrci(output, molden, state=1, cart_norm='auto', factored='auto')[source]¶

Wavefunction (basis + 1RDM + 2RDM) of an OpenMolcas MRCI state. molden is the RASSCF Molden file of the same run (the orbitals MOTRA transformed).

pyxscat.interfaces.molpro¶

Molpro MULTI (CASSCF/MCSCF) wavefunctions: CI vectors from the output, orbitals from a Molden file written after the MULTI step (put,molden,file.mld).

Requirements on the Molpro input:

  • gprint,civector and config,det inside {multi ...} (determinant printout: strings of 2/a/b/0 over the active orbitals);

  • no point-group symmetry (symmetry,nosym);

  • the Molden file must hold the orbitals the CI vector refers to (the MULTI orbitals that put,molden writes right after the MULTI step).

Molpro writes each determinant with the creation operators in orbital order (1alpha 1beta 2alpha …); the phase to the alpha-first convention of pyxscat.ci is applied on reading (verified: the energies of all states are reproduced to 1e-8 Hartree).

Molpro prints CI coefficients with eight decimals and only those above its print threshold. Older versions default to 0.05, which can drop several per cent of the wavefunction: add gthresh,printci=0 to the input. A truncated vector triggers a warning (its printed weight is stored as printed_weight); each vector is renormalised after reading.

Example:

from pyxscat.interfaces import molpro
wf = molpro.from_multi("lif.out", "lif.mld", state=1)
pyxscat.interfaces.molpro.read_multi_output(path)[source]¶

Parse the last MULTI block of a Molpro output.

Returns a dict with nclosed, nactive, nactive_electrons, ms2 (2 S from the spin label) and states: {state number (1-based): {“dets”: [(a, b)], “coeffs”, “energy”}}.

pyxscat.interfaces.molpro.read_punch(path, nclosed=None, molden=None, output=None)[source]¶

CI vectors from a Molpro punch file (punch,file.pun).

Older Molpro versions write the MULTI CI vector to the punch file with seven decimals and a much lower threshold than the output printout, so it is the better source when the output vector is truncated. The punch file does not record the closed-shell count; it is taken from nclosed, or from a Molpro output, or from the electron count of the molden file (sum of its occupations). Returns the same dict as read_multi_output().

pyxscat.interfaces.deck¶

Read the HDF5 “deck” of thistle-dev (KirranderGroup/thistle-dev, schema v1).

A deck holds a primitive Cartesian basis, molecular orbitals over the primitives (mos/mmod, contraction and normalisation included), the geometry, the q grid and cutoffs (params), and the density in one of two representations (attribute rdm_mode):

MO rdm/onerdm_mo and rdm/mo2rdm in the orbital basis (chemists’ notation, trace

N(N-1), PySCF’s convention). Here every primitive becomes its own function and the densities are transformed with mmod.

AO rdm/gamma_ao (total) or rdm/onerdm_ao (elastic) over contracted functions,

with basis/contr and contraction/coeffs defining them: exactly pyxscat’s Basis. Without a one-particle density (total decks) it follows from the two-particle one, D = sum_rs Gamma[:, :, r, s] S_rs / (N - 1), with N(N - 1) = sum Gamma S S.

Arrays were written in Fortran order; read back from Python they come with reversed axes, which is harmless here: the 1RDM is symmetric and the 2RDM is invariant under reversing all four indices. Checked against the five test decks of thistle-dev to 4e-13 (with the deck’s cutoffcentre); see benchmarks/thistle_dev_crosscheck.

pyxscat.interfaces.deck.is_deck(path)[source]¶

True for an HDF5 file with the attributes of a thistle-dev deck.

pyxscat.interfaces.deck.read(path)[source]¶

(Wavefunction, info) from a deck; info holds the q grid, cutoffs, observable, states and the representation.

pyxscat.interfaces.deck.write(path, wf, observable='total', q=None, cutoffcentre=0.01, cutoffz=1e-20, cutoffmd=1e-20, states=None, typec=None, file_out='scattering_out.dat', max_gb=8.0)[source]¶

Write a wavefunction as a thistle-dev deck (HDF5 schema v1, AO representation), the input of its Fortran and Julia engines.

observable

"total" writes the two-particle density (rdm/gamma_ao, chemists’ notation, trace N(N-1)); "elastic" the one-particle density (rdm/onerdm_ao).

q

the q grid for the deck’s params (bohr^-1, evenly spaced; default 1e-10 to 10, 200 points). cutoffcentre defaults to thistle-dev’s 0.01 (THISTLE itself uses the exact limit), so that both codes compute the same numbers.

The deck format holds the four-index array: a factored density is expanded here, up to max_gb gigabytes. The orbitals in mos are natural orbitals of the 1RDM.
