thistle: the simple interface¶

THISTLE: X-ray and electron scattering from wavefunctions, the simple way.

import thistle as th

wf = th.load(“water.molden”) # any supported input, auto-detected res = wf.scattering(qmax=4) # q in 1/Angstrom by default res.plot(“water.png”); res.save(“water.csv”)

th.compare(wf.scattering(), wf.iam()).plot() # molecule vs independent atom model e = wf.scattering(probe=”electron”) # electron diffraction cross section th.sm(e, wf.iam(probe=”electron”)).plot() # modified scattering sM(s) wf.detector(wavelength=1.0).plot(“image.png”) # fixed orientation, detector image wf.detector(grid=”polar”, energy_kev=10) # … on the polar grid of grid.f90 wf.aligned_ensemble(axis=(0, 1, 0), p2=0.5) # partially aligned molecules (j2)

Everything here is a thin layer over pyxscat; the full control (cutoffs, density providers, raw arrays) stays available there.

Authors: Andrés Moreno Carrascosa, Mats Simmermacher, Patrick Yuheng Wang, Eirik Moen Liane, Joseph Cooper, Nikola Zotev, Thomas Northey and Adam Kirrander.

thistle.core¶

User-facing objects: load anything, get a Molecule, ask it for scattering.

thistle.core.load(source, molden=None, state=1, punch=None, name=None, hf=False, factored='auto', mo_coeff=None)[source]¶

Load a wavefunction from (almost) anything.

source

  • a PySCF object: SCF (RHF/RKS), CCSD, CISD, CASSCF/CASCI (any active-space solver, DMRG and SHCI included) or a standalone FCI / selected-CI solver (fci.FCI(mf))

  • a Molden file (orbitals and occupations: elastic and mean-field scattering)

  • an OpenMolcas RASSCF output (its .rasscf.molden is found automatically); if the run went on to the uncontracted MRCI with THRPrint = 0.0, the MRCI state is read

  • a thistle-dev input deck (deck.h5, MO or dense-AO representation)

  • a Molpro MULTI output or punch file (the Molden file next to it is found). The output is not needed: a punch file and the Molden file are enough, and a missing output is replaced by the punch file of the same name. A Molden file together with punch= is read as that MULTI calculation.

state

root / state number for multi-state calculations (1 = lowest)

hf

the orbitals are those of a closed-shell Hartree-Fock calculation. A Molden file holds only orbitals and occupations, which give the elastic scattering; for a closed-shell determinant they also fix the pair density, hence the total and inelastic scattering. This is not true for natural orbitals of a correlated calculation, so it has to be said. (A PySCF RHF object is recognised by itself.)

factored

how a correlated two-particle density is held: "auto" (default) as products of one-particle matrices beyond 60 basis functions (no n^4 array), True always, False never. Same numbers either way (to ~1e-12); see THEORY §1.2 and §4.

mo_coeff

orbitals of a standalone PySCF FCI solver, which keeps only its integrals: the SCF object or the orbital array (th.load(fci.FCI(mf).run(), mo_coeff=mf))

thistle.core.sm(molecule, iam, curve='total')[source]¶

Modified scattering intensity sM(s) = s (I - I_at) / I_at of electron diffraction, with I_at the atomic part of the independent atom model (s = q, in the unit of the results).

Two curves: the ab initio molecule, and the IAM itself (s I_mol / I_at, the usual simulation); their difference is the effect of bonding and electron correlation.

scattering(q=None, qmax=4.0, points=201, unit='1/A', parts='standard', threads=None, probe='xray', energy_kev=None)[source]¶

Rotationally averaged scattering (gas phase, isotropic sample).

probe

"xray": intensity in electron units (Thomson cross section = 1). "electron": differential cross section dsigma/dOmega (first Born approximation) in Angstrom^2/sr (bohr^2/sr with unit="1/bohr"); NaN at q = 0. energy_kev adds the relativistic factor gamma^2 of the beam electrons.

parts

"standard": total, elastic, inelastic (elastic only if the input has no 2RDM) "all": X-rays: also Hartree, exchange and correlation (cumulant) parts; electrons: also the nucleus-nucleus, electron-nucleus and electron-electron terms.

anisotropy(q=None, qmax=4.0, points=201, unit='1/A', threads=None, probe='xray', energy_kev=None)[source]¶

Second Legendre moment S2(q) about the molecular z axis (partially aligned molecules): I(q, theta) = I0(q) + 5 <P2> P2(cos theta) S2(q) + … (the same relation for electrons, in cross-section units).

iam(q=None, qmax=4.0, points=201, unit='1/A', basis='aug-cc-pvtz', source='ab initio', probe='xray', energy_kev=None)[source]¶

Independent atom model on the same grid, for compare() (and sm() for electrons).

For electrons the curves also contain atomic (sum over atoms) and molecular (interference) parts.

detector(wavelength=None, qmax=None, pixels=101, orientation=(0.0, 0.0, 0.0), unit='1/A', parts='standard', threads=None, probe='xray', energy_kev=None, grid='square', theta_max=None, rings=49, azimuths=72, model='ab initio', iam_basis='aug-cc-pvtz', iam_source='ab initio')[source]¶

Scattering for one molecular orientation (oriented molecules, single detector images).

Beam: wavelength (Angstrom) or energy_kev (photon energy for X-rays, kinetic energy for electrons). Defaults: 1 Angstrom X-rays, 100 keV electrons. The beam runs along z; orientation = Euler angles (degrees, z-y-z) of the molecule.

grid

"square": a pixels x pixels image in (q_x, q_y) up to qmax (in unit; default: as far as the detector reaches, at most 12 1/A) -> DetectorImage. "polar": the qgrid3d/qcoord3 grid of the earlier code: rings rings up to the scattering angle theta_max (degrees; default 60 for X-rays, for electrons the angle reaching qmax, default 12 1/A), azimuths points per ring, plus q = 0 (49 rings, 72 azimuths, 60 degrees by default) -> DetectorPattern. a file name (columns qx qy qz in bohr^-1, e.g. qgrid.dat) or an (n, 3) array of laboratory q vectors (bohr^-1) -> DetectorPattern.

model

"ab initio" (the wavefunction) or "iam" (independent atoms on the same grid, free atoms in iam_basis; compare the two with compare()).

aligned_ensemble(axis=(0.0, 0.0, 1.0), p2=1.0, grid='polar', wavelength=None, energy_kev=None, theta_max=None, rings=49, azimuths=72, qmax=None, pixels=101, unit='1/A', threads=None, probe='xray', model='ab initio', iam_basis='aug-cc-pvtz', iam_source='ab initio')[source]¶

Detector pattern of molecules whose z axis is aligned along axis (laboratory frame, e.g. the laser polarisation; the beam runs along z) with degree of alignment p2 = <P2(cos beta)>, from the isotropic signal and the j2 moment:

I(q) = I0(|q|) + 5 p2 P2(q^ . axis^) S2(|q|)     (terms l >= 4 neglected)

I0 and S2 are rotational averages, computed once per distinct |q| (once per ring on the polar grid). Grids and model ("ab initio" or "iam") as in detector().

thistle.inputfile¶

Plain-text input files and the thistle command.

thistle new water.toml # write a commented template to fill in thistle run water.toml # compute everything it asks for, write CSV + PNG thistle check orbitals.molden # is this file read correctly? thistle submit water.toml # write (and optionally send) a Slurm job script thistle plot results/water_scattering.csv [–iam results/water_iam.csv] # (re)draw a plot

thistle.inputfile.template(path)[source]¶

Write a commented input file to fill in.

thistle.inputfile.run(path, verbose=True, **overrides)[source]¶

Do everything an input file asks for. Returns {name: written file}.

path may also be a calculation file (Molden, Molcas/Molpro output): then the default settings are used. overrides (state, qmax, points, unit, parts, iam, anisotropy, prefix) replace the corresponding settings; detector={...} and alignment={...} add/update those sections.

Besides the data (CSV, .dat, .npz) and plots (PNG), every run writes <prefix>_plots.py, a short script that redraws every plot from the data files (edit it to change the plots), and <prefix>_run.json with the settings, the time of each step and the file list.

thistle.plotting¶

Plots for every THISTLE calculation, from results in memory or from the files that thistle run writes.

import thistle as th import thistle.plotting as tp

res = mol.scattering() # or tp.read(“results/lif_scattering.csv”) tp.scattering(res, path=”lif.png”) # total, elastic, inelastic (and parts) tp.versus_iam(res, mol.iam()) # molecule and IAM, and the % difference below tp.sm(th.sm(e, mol.iam(probe=”electron”))) # electrons: sM(s) tp.anisotropy(mol.anisotropy()) # j2 moment tp.detector(mol.detector(grid=”polar”)) # a detector image or a pattern on any grid tp.detector_versus_iam(pat, iam_pat) # molecule, IAM, % difference tp.overlay([res1, res2], “total”, labels=[“state 1”, “state 2”]) tp.plot_file(“results/lif_vs_iam.csv”) # the right plot for any file THISTLE wrote

Every function returns the matplotlib Figure (fig.axes for further changes) and saves it when path is given. Curves keep the same colour in every plot (total blue, elastic orange, inelastic green, …), from a palette checked for colour-blind readers.

Molecule and independent atom model on the same grid (top) and the percent difference 100 (I - I_IAM) / I_IAM (bottom). curve: total if both have it, else elastic.

A percent-difference curve as written by compare (*_vs_iam.csv).

Modified scattering intensity sM(s) of electron diffraction: molecule (solid) and the IAM simulation (dashed).

One curve from several results (states, methods, basis sets) on the same axes; each result takes the next palette slot.

thistle.plotting.detector(obj, curve=None, path=None, log=True, title=None)[source]¶

A detector image (square grid) or pattern (polar grid, q-grid file): log colour scale for intensities, a diverging scale for signed data (differences).

thistle.plotting.detector_versus_iam(obj, iam, curve='total', path=None, title=None)[source]¶

Three panels on the same grid: molecule, IAM (one shared log scale) and the percent difference (diverging scale centred on zero).

thistle.plotting.read(path)[source]¶

Any file thistle run writes, back as the object that wrote it: a .csv gives a Result, a .npz a DetectorImage (or pattern), a .dat a DetectorPattern.
