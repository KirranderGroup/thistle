PyXSCAT - spin-summed 1- and 2-RDMs of a determinant expansion, bitwise

The determinant-pair ("bitwise") algorithm of the earlier code (twordm_jeremy.f90): every pair (I, J) is screened with popcnt(ieor(.)) and only pairs differing by at most two spin-orbitals contribute, through the Slater-Condon rules. Cost ~ N_det^2 for the screening (a few machine instructions per pair, OpenMP over I) plus the coupled pairs; independent of the size of the full CI space.

Any number of orbitals: each spin string is nw = ceil(norb / 64) 64-bit words (orbital k in word k/64, bit mod(k, 64)). The RDMs are accumulated in thread-private copies when nthreads x 8 norb^4 bytes is small (< 2 GB), otherwise straight into the shared arrays with atomic updates (norb = 300: a 6.5 GB dm2, one copy).

Conventions (as pyxscat.ci): determinant = alpha creators (ascending) then beta creators (ascending) on the vacuum;

 dm1[p,q]     = sum_sigma <a+_{p sigma} a_{q sigma}>
 dm2[p,q,r,s] = sum_{sigma tau} <a+_{p sigma} a+_{r tau} a_{s tau} a_{q sigma}>

(C order on the Python side: here d1(q,p) and d2(s,r,q,p)).

public subroutine rdm12_bitwise_groups(ndet, norb, nw, wa, wb, c, nint, ng, gstart, grp, nnb, nbstart, nb, d1, d2, nthreads, ierr)

The same pair loop restricted to candidate pairs: determinants are sorted into groups (contiguous, gstart(g):gstart(g+1)-1), and for group g only the groups nb(nbstart(g):nbstart(g+1)-1), all >= g, are paired with it (g itself first when it is to be included). Elements of dm2 with all four orbitals >= nint are not accumulated (they are formed elsewhere); nint < 0 keeps them. The (I, J) / (J, I) symmetrisation is applied as in rdm12_bitwise, so pairs must be listed once (g <= g').
