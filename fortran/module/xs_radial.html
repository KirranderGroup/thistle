PyXSCAT - radial functions shared by the one- and two-centre j0 kernels

 g_n(x) = j_n(x) / x^n                       (stable for every x >= 0)
 a(T, i) = T! / (i! (T-2i)! 2^i)               (Cartesian derivatives of a function of h^2/2)

For any radial function f(|h|) with f_n = (1/h d/dh)^n f,

 d^T/dhx^T d^U/dhy^U d^V/dhz^V f = sum_ijk a(T,i) a(U,j) a(V,k) hx^(T-2i) hy^(U-2j) hz^(V-2k)
                                   f_(T+U+V-i-j-k),

and for f = j0(q h): f_n = (-q^2)^n g_n(q h).

public pure function upward_threshold(kk)

The upward recurrence g(m+1) = [(2m+1) g(m) - g(m-1)] / x^2 is stable only while the order stays below x (above it the irregular solution y_m takes over, and rounding errors grow like (2m-1)!! (2m+1)!! / x^(2m+1)). It is therefore used only when x > kk + 1, for all orders at once; below that, jn_over_xn propagates downward (series + downward recurrence for x < 1, Miller's normalised backward recurrence for 1 <= x <= kk + 1).
