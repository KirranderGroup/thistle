PyXSCAT - C-compatible entry points (called from Python through ctypes)

One bind(C) wrapper per kernel; the ctypes signatures on the Python side are declared in python/pyxscat/_lib.py. Scalars are passed by value, arrays by reference in Fortran order, optional arrays as NULL pointers; nthreads > 0 sets the OpenMP thread count for the call.


Uses

    • xs_pairft
    • xs_rdm
    • xs_nuclear
    • xs_elastic
    • omp_lib
    • iso_c_binding
    • iso_fortran_env
