rdm12_bitwise xs_rdm Subroutine

Spin-summed d1 and d2 of the expansion with coefficients c over the determinants (wa(:, I), wb(:, I)), by the pair loop over all (I, J) on nthreads OpenMP threads. ierr = 1 when a determinant has more than maxocc occupied spin-orbitals.
rdm12_bitwise_groups xs_rdm Subroutine

The same pair loop restricted to candidate pairs: determinants are sorted into groups (contiguous, gstart(g):gstart(g+1)-1), and for group g only the groups nb(nbstart(g):nbstart(g+1)-1), all >= g, are paired with it (g itself first when it is to be included). Elements of dm2 with all four orbitals >= nint are not accumulated (they are formed elsewhere); nint < 0 keeps them. The (I, J) / (J, I) symmetrisation is applied as in rdm12_bitwise, so pairs must be listed once (g <= g').

upward_threshold xs_radial Function

The upward recurrence g(m+1) = [(2m+1) g(m) - g(m-1)] / x^2 is stable only while the order stays below x (above it the irregular solution y_m takes over, and rounding errors grow like (2m-1)!! (2m+1)!! / x^(2m+1)). It is therefore used only when x > kk + 1, for all orders at once; below that, jn_over_xn propagates downward (series + downward recurrence for x < 1, Miller's normalised backward recurrence for 1 <= x <= kk + 1).
